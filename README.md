# Sistema-de-Estacionamiento-de-Veh-culos-java-
Programa desarrollado en Java que simula la estadía de vehículos en un estacionamiento. Permite registrar la patente, costos y estado de la estadía, además de ingresar y finalizar una estadía. También calcula el costo final sumando el costo del estacionamiento y el costo de la estadía.
